# JM 搜索器 – 单页应用

轻量级移动端单页应用，原生 HTML5+CSS3+JavaScript，无外部依赖。包含开始、搜索、详情三页面，通过 JS 控制显示隐藏。

## 更新优化（2026-07-23 最终）

- **详情页背景**：采用柔和的灰色（#b0b0b0）-白色-灰色渐变，避免纯黑，提升视觉舒适度；使用 `clip-path` 实现从中心向两侧展开的动画，背景全屏覆盖。
- **卡片均匀分布**：利用 `flex:1` 和 `justify-content: space-evenly` 使 4 个卡片在垂直方向上均匀分布，无论屏幕高度。
- **搜索按钮优化**：激活状态使用更深的蓝色（#4A9FD8）并添加阴影，与背景天蓝色明显区分，提高可识别性。
- **卡片透明度调整**：背景改为 `rgba(255,255,255,0.75)`，既能看清背景渐变，又保证文字清晰。


## 关键元素 ID 和 Class 命名对照表

### 搜索页面

| 元素           | ID              | Class          | 说明                     |
|----------------|-----------------|----------------|--------------------------|
| 关键词输入框   | `keyword-input` | `search-input` | 文本输入框               |
| 关键词按钮     | `keyword-btn`   | `search-btn`   | “前往”按钮               |
| JM 码输入框    | `jm-input`      | `search-input` | 文本输入框               |
| JM 码按钮      | `jm-btn`        | `search-btn`   | “前往”按钮               |

### 详情页面卡片

每个卡片 `<div class="card">` 包含三个 `<span>`：域名、状态、延迟。

- **卡片容器 ID**：`card-{序号}`（序号 1~4）
- **内部 span ID**：`card-{序号}-{字段}`，字段为 `domain`、`status`、`delay`  
  例如：`card-1-domain`、`card-1-status`、`card-1-delay`

## 技术实现

- **移动优先**：`viewport` + Flexbox，完美适配 375px~414px 屏幕。
- **CSS 变量**：统一管理颜色，便于维护。
- **平滑动画**：搜索页背景渐变、详情页背景展开动画。
- **交互反馈**：搜索按钮根据输入动态启用/禁用。

## 使用说明

1. 打开 `index.html`。
2. 点击“开始使用”进入搜索页。
3. 输入文字后“前往”按钮变为可点击，点击弹出模拟提示。
4. 点击齿轮 ⚙️ 进入详情页，查看服务节点卡片。
5. 点击“返回”回到搜索页。

## 兼容性

现代浏览器（Chrome, Firefox, Safari, Edge），需支持 CSS `clip-path` 和 `backdrop-filter`。
