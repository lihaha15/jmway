# jmway
最简单、最傻瓜式的 jM第三方客户端，即使你是一个新手小白，也可以完成操作

## 怎么下载

下载文件：[jmseach2_1.0_perf.apk](./jmseach2_1.0_perf.apk)

手机上按这几步来：

1. 点上面的 `jmseach2_1.0_perf.apk`
2. 点右上角的三个点 `···`
3. 点「Download」或者「下载」
4. 下载完成后，点安装

装好后，桌面上的名字是 JMway。

安装时手机可能会提示“未知来源”“风险应用”，选“允许”或者“仍要安装”就行。这个包不用 root。

如果提示“应用未安装”，先把手里的旧版卸载，再装这个。直接覆盖安装也可以，之前下载好的漫画不会丢。

## 这个软件是干嘛的

一个看 jM 的第三方客户端。装完打开，点“开始探索”，它会自动测几条线路，挑最快的那条进去。

不用自己找域名，不用配代理，也不用在 App 里注册账号。网页里该登录的还是登录，登录状态会记住。

安装包 3.4MB 左右，Android 5.0 以上基本都能装。

## 有什么功能

- 自动测速选线路，一条打不开就换一条
- 图片加载做过优化，同样的网络下看图更快
- 页面广告会尽量提前清掉，少占流量
- 深色界面，晚上看不刺眼
- 悬浮下载球，点一下输入 JM 码就能下载
- 支持把漫画下载到手机本地

## 常见问题

**打开一直转圈**

先换个网络试试。还不行就去节点页点右上角的刷新，重新测一次。

**图片加载慢**

第一次打开会慢一点，图片有缓存，第二次会快。如果一直慢，多半是当前线路的问题，换一条。

**安装失败**

先检查下载有没有完成。还不行就卸载旧版再装。

**弹出“跨站跳转提示”**

点“允许”。这是 App 在确认你要去新的线路，不是报错。

**要不要钱**

不要钱。
