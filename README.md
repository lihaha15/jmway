# jmway

最简单、最傻瓜式的 jM 第三方客户端，即使你是一个新手小白，也可以完成操作。

## 最低系统要求

**Android 4.4（KitKat，API 19）及以上**。

再老的系统（Android 4.3 及以下）装不上。Android 9 及以上的手机也能正常用。

## 先看这一段：签名变了

从 1.1.0 开始用的是新的签名证书，和 1.0.x 所有版本都不是同一个签名。

- 从 **1.0.x** 升级过来：必须先卸载旧版，否则会提示“应用未安装”。
- 从 **1.1.0 / 1.1.1** 升级：直接覆盖安装就行，不用卸载。
- 卸载会清掉 App 里的登录状态和设置；已经下载到 `Download/` 里的 zip 不会丢。

## 怎么下载

下载文件：[JMway-1.1.2.apk](./JMway-1.1.2.apk)

手机上按这几步来：

1. 点上面的 `JMway-1.1.2.apk`
2. 点右上角的三个点 `···`
3. 点「Download」或者「下载」
4. 下载完成后，点安装

装好后，桌面上的名字是 JMway。

安装时手机可能会提示“未知来源”“风险应用”，选“允许”或者“仍要安装”就行。这个包不用 root。

如果提示“应用未安装”，先按上面说的把旧版卸载，再装这个。

## 这个软件是干嘛的

一个看 jM 的第三方客户端。装完打开，点“开始探索”，它会自动测几条线路，挑最快的那条进去。

不用自己找域名，不用配代理，也不用在 App 里注册账号。网页里该登录的还是登录，登录状态会记住。

安装包 3.5MB 左右，Android 4.4 以上基本都能装。

## 有什么功能

- 自动测速选线路，一条打不开就换一条
- 图片加载做过优化，同样的网络下看图更快
- 页面广告会持续清理，进入页面后冒出来的广告也能去掉
- 深色界面，晚上看不刺眼
- 悬浮下载球，点一下输入 JM 码就能下载
- 支持把漫画下载到手机本地，自动打成 zip，不污染相册

## 常见问题

**安装时提示“应用未安装”**

从 1.0.x 升上来的话，先把旧版卸载再装。卸载不会删掉 `Download/` 里已经下好的 zip。

**打开一直转圈**

先换个网络试试。还不行就去节点页点右上角的刷新，重新测一次。

**图片加载慢**

第一次打开会慢一点，图片有缓存，第二次会快。如果一直慢，多半是当前线路的问题，换一条。

**下载完找不到文件**

在手机的 `Download/` 目录里，文件名是 `JM<漫画号>.zip`。用任意解压软件都能打开。

**弹出“跨站跳转提示”**

点“允许”。这是 App 在确认你要去新的线路，不是报错。

**某张图显示空白**

1.1.2 起，https 页面里的 http 图片会被拦掉。如果只是个别图空白，就是那张图本身是 http 的。

**要不要钱**

不要钱。
