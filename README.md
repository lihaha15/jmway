# jmway

最简单、最傻瓜式的 jM 第三方客户端，即使你是一个新手小白，也可以完成操作。

## 先看这一段：这次换了签名

1.1.0 换了新的签名证书，和之前所有版本都不是同一个签名。

- **装新版前，必须先卸载手机里的旧版**，否则会提示“应用未安装”。
- 卸载会清掉 App 里的登录状态和设置；已经下载到 `Download/` 里的 zip 不会丢。
- 这个卸载只需要做一次，以后可以正常覆盖更新。

## 怎么下载

下载文件：[JMway-1.1.0.apk](./JMway-1.1.0.apk)

手机上按这几步来：

1. 点上面的 `JMway-1.1.0.apk`
2. 点右上角的三个点 `···`
3. 点「Download」或者「下载」
4. 下载完成后，点安装

装好后，桌面上的名字是 JMway。

安装时手机可能会提示“未知来源”“风险应用”，选“允许”或者“仍要安装”就行。这个包不用 root。

如果提示“应用未安装”，先按上面说的把旧版卸载，再装这个。

## 最近更新（2026-11-13）

- 换了自己的签名证书（版本号 1.1.0 / versionCode 101000），安装前需要卸载旧版。
- 关掉了内置的自动更新检查。原来那个检查走 http 明文，而且指向的是官方原版壳，装不上，还容易被带偏。
- 关掉了系统备份，避免登录 Cookie 被备份带走。
- vConsole 调试面板改成只用安装包内的本地文件，不再从 4 个公共 CDN 下载脚本。
- 下载漫画后仍然自动打包成一个 zip，打包完删掉临时图片，相册里不会多出一堆图。

## 这个软件是干嘛的

一个看 jM 的第三方客户端。装完打开，点“开始探索”，它会自动测几条线路，挑最快的那条进去。

不用自己找域名，不用配代理，也不用在 App 里注册账号。网页里该登录的还是登录，登录状态会记住。

安装包 3.5MB 左右，Android 5.0 以上基本都能装。

## 有什么功能

- 自动测速选线路，一条打不开就换一条
- 图片加载做过优化，同样的网络下看图更快
- 页面广告会持续清理，进入页面后冒出来的广告也能去掉
- 深色界面，晚上看不刺眼
- 悬浮下载球，点一下输入 JM 码就能下载
- 支持把漫画下载到手机本地，自动打成 zip，不污染相册

## 常见问题

**安装时提示“应用未安装”**

这次换了签名，先把旧版卸载再装。卸载不会删掉 `Download/` 里已经下好的 zip。

**打开一直转圈**

先换个网络试试。还不行就去节点页点右上角的刷新，重新测一次。

**图片加载慢**

第一次打开会慢一点，图片有缓存，第二次会快。如果一直慢，多半是当前线路的问题，换一条。

**下载完找不到文件**

在手机的 `Download/` 目录里，文件名是 `JM<漫画号>.zip`。用任意解压软件都能打开。

**弹出“跨站跳转提示”**

点“允许”。这是 App 在确认你要去新的线路，不是报错。

**要不要钱**

不要钱。
