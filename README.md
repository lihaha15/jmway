# JMway

一个装好就能用的 jM 第三方客户端，新手也能直接上手。

不用自己找域名，不用配代理，也不用在 App 里另外注册账号。

## 下载安装

**下载文件：[JMway-1.0.0.1.apk](./JMway-1.0.0.1.apk)**

当前版本 **1.0.0.1**，比之前的 1.0 新，可以直接覆盖安装。

手机上按这几步来：

1. 点上面的 `JMway-1.0.0.1.apk`
2. 点右上角的三个点 `···`
3. 点「Download」或者「下载」
4. 下载完成后，点安装

装好后，桌面上的名字是 **JMway**。

安装时手机可能会提示「未知来源」「风险应用」，选「允许」或者「仍要安装」就行。这个包不用 root。

如果提示「应用未安装」，先把手里的旧版卸载，再装这个。之前装过旧版的，一般可以直接覆盖安装，下载好的漫画和登录状态都还在。

安装包 3.5MB 左右，Android 5.0 以上基本都能装。

## 这个软件是干嘛的

一个看 jM 的第三方客户端。装完打开，点「开始探索」，它会自动测几条线路，挑最快的那条进去。

不用自己找域名，不用配代理，也不用在 App 里注册账号。网页里该登录的还是登录，登录状态会记住。

## 有什么功能

- 自动测速选线路，一条打不开就换一条
- 页面广告会持续清理，进入页面后冒出来的广告也能去掉
- 下载自动打包成 zip，相册里不会多出图片
- 深色界面，晚上看不刺眼
- 悬浮下载球，点一下输入 JM 码就能下载

## 常见问题

**下载完找不到图片**

现在的图片是打包好的，去「文件管理 → Download」找 `JMxxxxx.zip`，解压就是整本图。

**打开一直转圈**

先换个网络试试。还不行就去节点页点右上角的刷新，重新测一次。

**图片加载慢**

第一次打开会慢一点，图片有缓存，第二次会快。如果一直慢，多半是当前线路的问题，换一条。

**安装失败**

先检查下载有没有完成。还不行就卸载旧版再装。

**弹出「跨站跳转提示」**

点「允许」。这是 App 在确认你要去新的线路，不是报错。

**要不要钱**

不要钱。
